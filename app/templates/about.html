Project Architecture & Authentication Design

1. Application Factory & Modular Blueprints

The project employs Flask's Application Factory pattern (create_app()) with distinct Blueprints:

  • auth_bp (/auth/register, /auth/login, /auth/logout, /auth/profile): User authentication and session lifecycle.
  • main_bp (/, /about, /health, /create-post): Core web views and post publishing.
  • api_bp (/api/users, /api/posts): RESTful JSON API endpoints.

2. Flask-Login & Session Management

User sessions are managed using Flask-Login:

  • UserMixin: Implements standard Flask-Login properties (is_authenticated, is_active, is_anonymous, get_id()).
  • @login_manager.user_loader: Dynamically loads the active user from the session database ID.
  • @login_required: Protects sensitive views, automatically redirecting unauthorized visitors to /auth/login?next=... with flash alerts.

3. Password Security & Hashing

Passwords are never stored in plaintext. Passwords undergo cryptographic salted one-way hashing using Werkzeug's security suite (generate_password_hash and check_password_hash).

4. Database Migrations (Flask-Migrate)

All schema updates are tracked through versioned Alembic scripts in migrations/, ensuring zero-loss schema upgrades.
