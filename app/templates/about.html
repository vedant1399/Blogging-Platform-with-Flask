System Architecture & Technical Design

Full stack architecture documentation across Weeks 1 to 4

1. Modular Jinja2 Templating & Macro Architecture (Week 4)

The presentation layer leverages Jinja2 template inheritance, custom filters, and reusable component macros (app/templates/_macros.html):

  • render_pagination Macro: Dynamically generates page numbers, previous/next states, active indicators, and query preservation.
  • render_post_card Macro: Reusable card layout rendering categories, tags, estimated reading time, author, and timestamp.
  • Custom Template Filters: reading_time (calculates estimated reading time based on word count) and format_datetime.
  • Breadcrumbs & Navigational Links: Multi-level breadcrumbs and sequential previous/next article browsing on individual post pages.
  • Public Author Profiles: Dedicated profile routes at /users/<username> displaying author metadata and paginated publication archives.

2. Blog Post CRUD & Taxonomy (Week 3)

  • Full lifecycle: Create, Read, Update, Delete with author-level authorization checks.
  • One-to-Many Category and Many-to-Many Tag relational modeling via the post_tags association table.
  • Flask-WTF form validation with CSRF security tokens and dynamic category pickers.
  • Quill.js Rich Text Editor integration with client-side synchronization.

3. User Authentication & Sessions (Week 2)

  • User registration, login, logout, and persistent session management powered by Flask-Login.
  • Cryptographic one-way password hashing using Werkzeug security functions (generate_password_hash).
  • Route protection with the @login_required decorator and session-aware navigation bar.

4. Core Architecture & Migrations (Week 1)

  • Application Factory pattern (create_app()) supporting development, testing, and production environments.
  • Four dedicated Blueprints: main_bp, auth_bp, posts_bp, and api_bp.
  • Database migrations tracked via Alembic / Flask-Migrate in migrations/.
