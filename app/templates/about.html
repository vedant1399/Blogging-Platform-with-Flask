System Architecture & Technical Design

Full stack architecture documentation across Weeks 1 to 6

1. Search & Advanced Filtering Engine (Week 6)

Implemented dynamic query construction utilizing SQLAlchemy's ORM querying patterns:

  • Case-Insensitive Full Search: Evaluates queries against article titles and article bodies simultaneously using db.or_(Post.title.ilike(...), Post.content.ilike(...)).
  • Taxonomy Filtering: Filter articles by Category or Tag, composable with active search queries.
  • Dynamic Multi-Criteria Sorting: Supports sorting by Newest, Oldest, and Popular (ordering by comment count via func.count(Comment.id)).
  • Global Search & Filter Toolbar: Global navigation search bar coupled with interactive toolbar on /posts/ with filter reset capabilities.

2. Commenting System & Relational Models (Week 5)

  • Comment model linked to User and Post with automatic cascade deletion.
  • Flask-WTF CommentForm validation and CSRF protection.
  • Dual-authorization moderation (comment author and post owner can delete comments).

3. Modular Jinja2 Templating & Pagination (Week 4)

  • render_pagination and render_post_card component macros.
  • Custom Jinja2 filters: reading_time and format_datetime.
  • Public author profiles (/users/<username>) and breadcrumb navigation.

4. Blog Post CRUD & Taxonomy (Week 3)

  • Complete CRUD lifecycle with author permission checks.
  • One-to-Many Category and Many-to-Many Tag relational modeling.
  • Quill.js rich text editor integration.

5. User Authentication & Sessions (Week 2)

  • Flask-Login authentication, session management, and salted password hashing.

6. Core Architecture & Migrations (Week 1)

  • Application Factory pattern (create_app()) with environment configurations.
  • Four dedicated Blueprints (main_bp, auth_bp, posts_bp, api_bp).
  • Alembic migrations via Flask-Migrate.
