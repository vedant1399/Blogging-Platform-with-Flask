Project Architecture & System Design

1. Modular Blueprints & Application Factory

Built using Flask's Application Factory pattern (create_app()) with distinct Blueprints:

  • posts_bp (/posts): Full CRUD lifecycle for posts, categories, tags, and rich text authoring.
  • auth_bp (/auth): Registration, authentication, logout, and protected profiles.
  • main_bp (/): Home dashboard and health metrics.
  • api_bp (/api): RESTful JSON endpoints.

2. Database Models & Relational Architecture

  • User: Auth credentials, session state (UserMixin), and password hash.
  • Post: Core entity containing title, slug, HTML content, timestamp, author foreign key, and category foreign key.
  • Category: One-to-Many relationship with Post (category.posts).
  • Tag & post_tags: Many-to-Many association table linking posts with reusable tags (post.tags).

3. Flask-WTF Forms & Validation

Form handling is implemented with Flask-WTF and WTForms, featuring CSRF tokens, length and data required validators, dynamic category selection, and comma-separated tag parsing.

4. Rich Text Editor (Quill.js)

The post creation and editing interface integrates the Quill.js rich text editor, enabling writers to format headers, bold/italic text, lists, blockquotes, and code blocks. Contents sync automatically into Flask-WTF fields before submission.

5. Database Migrations (Flask-Migrate)

Schema changes are tracked version by version in migrations/versions/ using Alembic, supporting database upgrades and rollbacks.
